# Finanças App

App Android pessoal para acompanhar a vida financeira a partir do Open Finance (via Meu Pluggy), sem nenhum banco de dados do lado do autor: os dados de cada usuário ficam no celular dele.

## Agent skills

### Issue tracker

Issues e o mapa do wayfinder ficam nas GitHub Issues deste repo (via `gh`). See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: um `GLOSSARY.md` e `docs/adr/` na raiz. See `docs/agents/domain.md`.
